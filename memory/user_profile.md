Dev junior (~2,5 ans d'expérience en entreprise, avec IA). Progression active vers intermédiaire.

**Zone de confort :** JavaScript / Node.js solide. React en cours d'apprentissage. NestJS peu connu — a utilisé le framework sur ce projet mais n'a pas encore lu le code backend en profondeur.

**Ce qu'il connaît bien :**
- JS/TS, logique algorithmique de base
- React (composants, hooks, état)
- SCSS — il aime ça et structure bien ses styles
- Git, Docker (utilisation basique)

**Ce qu'il apprend :**
- NestJS : les décorateurs (`@Module`, `@Injectable`, `@Controller`), l'injection de dépendances, les guards, Passport/JWT — opaque pour lui, à documenter au passage
- Les patterns React avancés (custom hooks, gestion d'état complexe)

**Posture :** veut comprendre et posséder son code, pas juste recevoir du code fonctionnel. Ne commit jamais du code qu'il ne comprend pas.

**Profil projet :** seul développeur et administrateur de l'app ÉducMentor. Possède un NAS Synology DS220+. Décisions techniques pragmatiques : SQLite, Docker, Tailscale.
